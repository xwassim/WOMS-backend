# WOMS — Backend

Backend of the **Well Operations Monitoring System (WOMS)**, an academic team project developed at ESI Algiers during the 2024/2025 academic year.

## About

WOMS is a digital platform designed to centralize, monitor and analyze oil drilling operations.

The backend handles the application's business logic, operational reports, drilling data, performance indicators and communication with the frontend.

## Technologies

- Java
- Spring Boot
- Maven
- Oracle Database
- REST API
- JWT Authentication

## Main Features

- REST API for the WOMS frontend
- User authentication and role management
- Operational report processing
- Drilling data management
- Cost and schedule deviation analysis
- Dashboard data generation
- Planning and monitoring services
- Secure storage of drilling information

## Architecture

The backend follows a layered architecture based on:

- Controllers
- Services
- Repositories
- Models
